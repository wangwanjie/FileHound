FileHound

不建索引的 macOS 文件搜索工具。每次直接搜索磁盘，找到 Spotlight 找不到的文件：系统目录、隐藏文件、包内容，一个不漏。 An index-free file search tool for macOS. It searches the disk directly every time and finds what Spotlight misses — system folders, hidden files and package contents.

安装Install

不确定芯片类型？打开「苹果菜单 › 关于本机」，看“芯片”或“处理器”一栏。Not sure which chip you have? Open › About This Mac and check “Chip” or “Processor”.

  1. 下载与本机芯片匹配的 DMG，打开后把 FileHound 拖进「应用程序」文件夹。Download the DMG for your chip, open it and drag FileHound into Applications.
  2. 在「系统设置 › 隐私与安全性 › 完全磁盘访问权限」中允许 FileHound，偏好设置的「权限」页可以检查授权状态。Allow FileHound in System Settings › Privacy & Security › Full Disk Access. The Permissions pane in Settings shows the current status.
  3. 需要搜索仅 root 可读的位置（如 /private/var/root）时，在「权限」页安装特权辅助程序，并在「系统设置 › 通用 › 登录项」中允许。To search root-only locations such as /private/var/root, install the privileged helper from the Permissions pane and allow it in System Settings › General › Login Items.
  4. 应用内会自动检查更新，只会下载与本机芯片匹配的版本。FileHound checks for updates automatically and only downloads the build for your chip.

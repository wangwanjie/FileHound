## 新功能

- 导出结果：可以把当前结果导出为 CSV 或纯文本路径列表（文件 > 导出结果…，⇧⌘E；结果窗口工具栏和右键菜单中也有入口）
- 可以把结果从列表、树形、网格视图直接拖到访达或其他 App
- 把访达中的文件夹拖到查找窗口，即可把它设为搜索范围
- 偏好设置中的「慢速搜索」文件夹现在会生效：这些文件夹会在其他位置都搜完之后再搜索

## 改进

- Spotlight 预取改为与目录遍历同时进行，搜索过程中可以随时停止，第一批结果出现得更早
- 按日期、大小、正则等条件搜索时，条件只在开始时解析一次，搜索大量文件时明显更快
- 「注释」条件不再逐个文件查询 Spotlight，搜索整个磁盘时快很多
- 文件大小单位与访达一致：KB / MB / GB 按 1000 进制，KiB / MiB / GiB 按 1024 进制；支持「1,024」这样带千分位的写法
- 多个查找窗口同时搜索时互不拖慢
- 启动时改为在后台检查更新，没有新版本时不再弹窗；「每天自动检查」现在真正生效；在偏好设置中修改更新选项后立即生效
- 应用内选择的浅色 / 深色外观同样作用于结果窗口和各类弹窗
- 切换语言后，已打开的结果窗口也会立即更新文案
- 插拔磁盘后，搜索范围菜单中的卷宗列表会自动更新；同名卷宗可以分别选择
- 结果很多时，结果窗口刷新更流畅
- 改进 VoiceOver 朗读：按钮和控件使用本地化的名称

## 修复

- 文本内容搜索可能把只有文件名包含关键词的文件（甚至文件夹）当成命中；有 Spotlight 结果时会漏掉 Spotlight 没有收录的文件
- 多个条件组合时，Spotlight 查询的优先级错误，可能返回不满足全部条件的结果
- 忽略变音符号时，搜索整个卷宗可能找不到带变音符号的文件名（例如用「cafe」找「café」）
- 区分大小写、忽略变音符号搜索文本内容时，「Resume」找不到「Résumé」
- 输入很大的文件大小数值时 App 崩溃
- 「种类是视频」会把音频文件也算进来
- 在应用程序包内搜索并关闭「包内容」时，没有任何结果
- 「今天 / 昨天」日期条件会匹配所有文件
- 「不可见项目」在不同搜索方式下判断不一致，可能进入 ~/Library 等隐藏文件夹
- 用键盘或 ⌘A 改变选中后，打开、移到废纸篓、拷贝等操作仍然作用于之前选中的项目
- 树形视图中，路径分叉时生成错误的上级文件夹；补出的上级文件夹可以被移到废纸篓或删除
- 树形视图中折叠的文件夹在结果刷新后被重新展开
- 搜索进行中移除、移到废纸篓或重命名的结果，会在下一次刷新时重新出现
- 重命名时没有检查名称是否合法；重命名文件夹后，其中的结果路径失效
- 设为不可见、解锁失败时没有任何提示
- 文件名包含 emoji 时，名称高亮的位置错位
- 关闭「结果窗口跟随查找窗口」后，⌘R 重新搜索没有反应
- 新搜索没有结果时，绑定的结果窗口仍然显示上一次的结果
- 多显示器下增删条件时，查找窗口会跳到主显示器
- 快捷键录制框无法录制与菜单冲突的组合，录制 ⌘Q 会直接退出 App
- 已存储搜索、搜索历史或特殊文件夹配置中有一条数据损坏时，其他数据也会丢失（现在会跳过损坏的条目并备份原始数据）
- 开启「打开最近搜索」菜单后，已存储搜索的重命名、删除菜单失效
- 外观偏好中手动输入的字号不会保存
